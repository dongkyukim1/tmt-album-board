# tmt-album-board(웹) 필요작업 로드맵

> 갱신: 2026-07-30 · **토스터 메이커 전면 개편** — 손그림 와이어프레임(IMG_2907) 기준으로 웹을 블라인드 리뷰 보드에서 토스터 메이커로 재구축.
> 빈 그리드 → 칸 클릭 검색 삽입 → 전부 채움+한줄평 → 로그인 게이트 → 저장(POST/PUT /charts) → 앱 확인/이미지 다운로드.
> 추가: 내 토스터 목록·편집·삭제, 공개 토스터 레일, 로컬 목 모드(`npm run mock` → `?mock=1`), Pretendard.
> 백엔드(music-api)는 기존 charts/itunes/auth 계약으로 전부 커버 — 스키마·엔드포인트 변경 불필요 확인.

## 개편 이후 남은 작업

- [ ] **비정방형/대형 토스터 편집** — 앱은 최대 20×20 지원, 웹 편집은 3/4/5 정방형만. 뷰어는 공유 페이지로 커버
- [ ] **스타일 편집** — style(배경색·제목/번호 표시 등)은 기본값 전송 중. 앱 스타일을 웹에서도 편집할지 결정
- [ ] **차트 verdict(taste/hmm/respect)** — 공개 토스터에 평가 남기기(백엔드 API 이미 존재)
